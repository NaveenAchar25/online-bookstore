# Bookstore Frontend

React application for the Online Bookstore, built with Vite and TypeScript.

## Requirements

- Node.js 18 or later

## Setup

```bash
cd bookstore-frontend
npm install
```

## Running the app

```bash
npm run dev
```

Opens at `http://localhost:5173`.

## Type-checking

```bash
npm run typecheck
```

Runs the TypeScript compiler in build mode with no output.
`npm run build` also runs this automatically before bundling,
so a type error fails the build.

## Running tests

```bash
npm test
```
